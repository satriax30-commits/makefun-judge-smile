A tiny deterministic program (Node 22, standard library only) that writes one
line — at most 200 characters — about a small good thing that happened today
to `/output/entry.txt`. The line: a warung lady slips an extra fried egg onto
the morning rice and whispers "for the road", and that small kindness gets
carried home like sunlight in a pocket.

Run it with:

```
node main.ts
```

It creates `/output` if needed and writes the single line, byte-identical on
every run. No clock, no randomness, no network.
